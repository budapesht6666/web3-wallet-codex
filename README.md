# Web3 Wallet Codex

Одностраничное приложение на React для отправки тестовых токенов ARB в сети Arbitrum Goerli.

## Возможности

- Проверка наличия MetaMask и подключение кошелька одним кликом.
- Контроль правильности сети (Arbitrum Goerli, chainId `421613`).
- Отображение адреса и баланса токенов ARB пользователя.
- Валидация адреса получателя и суммы перевода с учётом остатка на счёте.
- Отправка транзакции `transfer` и ссылка на Arbiscan после подтверждения.

## Требования

- Node.js 18+
- npm 9+

## Установка и запуск

```bash
npm install
npm run dev
```

После запуска откройте [http://localhost:5173](http://localhost:5173) и подключите MetaMask.

## Добавление сети Arbitrum Goerli в MetaMask

1. Откройте MetaMask и перейдите в список сетей.
2. Нажмите «Добавить сеть» и введите параметры:
   - **Название сети:** Arbitrum Goerli
   - **RPC URL:** `https://goerli-rollup.arbitrum.io/rpc`
   - **Chain ID:** `421613`
   - **Валюта:** `ETH`
   - **Block Explorer URL:** `https://goerli.arbiscan.io`
3. Сохраните и переключитесь на новую сеть.

## Тестовые токены ARB

Для получения тестовых токенов воспользуйтесь любым доступным Arbitrum Goerli faucet и укажите адрес своего кошелька. После поступления токенов обновите страницу или переподключите кошелёк, чтобы увидеть баланс.
